# Introduction

This folder contains the code for the paper: 

### Yan Lin, Rui Shen, Jasmine Wang, and Y. Julia Yu, "Global Evolution of Environmental and Social Disclosure in Annual Reports"  at the Journal of Accounting Research, 62(5), 1941-1988

├── gen-word2vec: Scripts for training the word2vec model and getting the keywords 

└── score: Calculating the key metrics in the paper: Length, Specificity, Boilerplate, Stickiness, and Visuals (Tables and Images)

All the scripts are intended to be run as a standalone Python script by calling: 

```bash
python <filename>.py
```
